# Установка и удаление MapHints

## 1. Требования

Windows x64 и установленная Heroes of Might and Magic: Olden Era, Steam build 26428102.

Для первой установки нужен интернет. Установщик загружает BepInEx Unity.IL2CPP 6.0.0-be.788 и базовые библиотеки Unity 6000.0.66 с серверов BepInEx, затем проверяет их SHA-256. Уже установленные совпадающие зависимости повторно не скачиваются.

## 2. Установка

1. Скачайте [установочный архив OldenEra-MapHints-0.3.15.zip](https://github.com/yusha144/OldenEra-MapHints/releases/download/v0.3.16/OldenEra-MapHints-0.3.15.zip).
2. Распакуйте ZIP целиком в отдельную папку вне каталога игры.
3. Закройте игру и запустите `Install.bat` из корня распакованного архива.
4. Сверьте путь, который показывает установщик. Если он выводит список копий игры, введите номер нужной копии. Если установщик просит путь, откройте папку установленной игры через библиотеку Steam и укажите полный путь к папке с `HeroesOldenEra.exe`.
5. При запросе подтверждения введите `1` и нажмите Enter. Для отмены введите `2`. Дождитесь сообщения об успешном завершении.
6. Запустите игру через Steam.

Первый запуск с BepInEx занимает дополнительное время на создание библиотек мода.

Прямая ссылка в первом шаге ведёт к готовому установщику. На странице выпуска его также можно найти по полному имени ZIP из первого шага.

Для проверки целостности установочного ZIP сравните SHA-256 с соседним файлом `.zip.sha256`:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'
```

DLL мода устанавливается в `BepInEx/plugins/MapHints/OldenEra.MapHints.dll`. Предыдущие файлы сохраняются в `BepInEx/MapHints-backups/<дата-идентификатор>`. Старые дубликаты DLL внутри plugins также сохраняются в копии и убираются.

Установщик сохраняет существующие настройки. При обнаружении отличающегося загрузчика или отключённого `doorstop_config.ini` он останавливается с сообщением. При ошибке записи выполняется откат заменённых файлов; результат выводится в окне установщика.

## 3. Проверка работы

Откройте карту и выберите героя. У видимых объектов появляются отметки. По умолчанию F8 переключает все отметки, доступные награды и скрытие.

В `BepInEx/LogOutput.log` успешная загрузка отмечена строкой `Map Hints 0.3.16 loaded`. Сообщение `supports Steam build 26428102 only` означает несовместимость игровых файлов.

Размер отметок и клавиша переключения меняются в [настройках](settings.md).

## 4. Обновление и откат

Для обновления распакуйте новый установочный архив отдельно, закройте игру и запустите его `Install.bat`. Настройки MapHints, общие клавиши и другие моды сохраняются.

Для отката откройте резервную копию по пути из окна установщика. При закрытой игре верните прежнюю DLL в `BepInEx/plugins/MapHints`. При необходимости верните файл `local.oldenera.maphints.cfg` из копии.

Файл `backup.json` перечисляет сохранённые файлы. Восстанавливайте нужные файлы по отдельности. Дубликаты DLL в других папках plugins возвращать не нужно. Общий файл клавиш перед восстановлением сравните с текущим, чтобы сохранить изменения других модов. Откат DLL не меняет версию игры.

## 5. Удаление

Закройте игру и запустите `Uninstall.bat` из папки распакованного установщика. Проверьте путь к игре. При запросе подтверждения введите `1` и нажмите Enter. Для отмены введите `2`.

Удаление убирает все копии `OldenEra.MapHints.dll` внутри plugins. Настройки MapHints, общие клавиши, резервные копии, BepInEx и другие моды остаются на месте. Интернет для удаления не нужен.

Для сброса настроек удалите только `BepInEx/config/local.oldenera.maphints.cfg`.

Без установочного архива можно удалить DLL MapHints и её дубликаты вручную при закрытой игре. Всю папку BepInEx удалять не нужно.

## 6. Если возникла ошибка

| Сообщение или симптом | Действие |
|---|---|
| Это архив исходников MapHints / Это исходники установщика | Скачайте установочный архив по ссылке в разделе 2 и распакуйте его целиком |
| Не найден `_files/Install.ps1` | Распакуйте установочный ZIP целиком в отдельную папку и запустите `Install.bat` из папки распаковки |
| Версия игры не подходит | Сверьте Steam build с требованиями |
| Другой или изменённый загрузчик | Укажите установленную версию BepInEx в обращении к автору |
| Загрузка не удалась | Проверьте доступ к серверам BepInEx и повторите установку |
| Отказано в доступе | Закройте игру и проверьте право записи в выбранную папку |
| Нет отметок | Выберите героя, проверьте назначенную клавишу, Display.Enabled, видимость объектов и журнал |
| Нет панели навыков | Познакомьтесь со зданием своим героем |

Проверка совместимости без установки запускается из папки распакованного архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_files\Install.ps1 -GamePath '<папка игры>' -VerifyOnly -NonInteractive
```

В этом режиме нет скачивания и изменения файлов игры.
