# Настройки MapHints

## 1. Отметки на карте

Настройки находятся в папке игры: `BepInEx/config/local.oldenera.maphints.cfg`. Файл создаётся при первом запуске мода. Изменяйте его при закрытой игре.

| Секция | Параметр | По умолчанию | Действие |
|---|---|---|---|
| Display | Enabled | true | Включает подсказки |
| Display | Mode | All | All: все отметки, Available: доступные награды, Off: скрытие |
| Display | IconSize | 32 | Размер значка, от 20 до 64 |
| Display | MarkerScale | 0.84 | Общий масштаб отметок, от 0.35 до 1.5 |
| Display | SkillHoverPreview | true | Панель известных навыков при наведении на здание |
| Display | PulseManaWells | true | Выделение колодцев при неполной мане |
| Diagnostics | LogStateChanges | false | Запись смены героя и количества отметок в журнал |

Колодец отображается и в режиме Available при полной мане, но без выделения нехватки маны. Изменения настроек применяются после перезапуска игры.

## 2. Клавиша переключения

Общие клавиши находятся в `BepInEx/config/OldenEra.hotkeys.cfg`. Если этого файла нет, мод читает существующий `yusha144.hotkeys.cfg`. Если нет обоих файлов, создаётся `OldenEra.hotkeys.cfg`.

В секции `Hotkeys` параметр `MapHints` задаёт клавишу переключения. По умолчанию это F8. Пример изменения одной записи:

```ini
[Hotkeys]
MapHints = F8 + LeftControl
```

Сохраните остальные записи файла. Значение `None` отключает клавишу. После изменения перезапустите игру.

## 3. Как читаются подсказки

Отметки относятся к выбранному герою и видимым объектам карты. Яркая отметка означает доступную награду, приглушённая означает использованный объект или уже действующий бонус. Оранжевая отметка означает, что условия получения награды не выполнены.

Число 7 обозначает еженедельное обновление, число 1 обозначает ежедневное. Разделитель / между значками означает выбор одной награды.

Мельница и Волшебный сад обозначаются кубиком. Он показывает случайный характер награды без раскрытия выбранного игрой ресурса.

Университет, Мудрый сыч и Зловещий театр показывают известные навыки после знакомства со зданием одним из своих героев. Знание доступно остальным своим героям и сохраняется вместе с партией. Посещение противником не раскрывает предложения. При загрузке более раннего сохранения используются сведения из этого сохранения.

Панель показывает известный навык. Итоговый уровень и возможность обучения определяются игрой при посещении здания.

## 4. Журнал

Сообщения мода находятся в `BepInEx/LogOutput.log`. Для проверки загрузки найдите `Map Hints 0.3.12 loaded`. При несовпадении игровых файлов мод отключает подсказки и пишет `supports Steam build 25672315 only`.

Для подробной записи смены героя и отметок включите `Diagnostics.LogStateChanges`. После проверки верните значение false.
