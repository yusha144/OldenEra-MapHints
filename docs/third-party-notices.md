# Сторонние компоненты

Код MapHints, установщика и документация распространяются по [MIT](../LICENSE), Copyright (c) 2026 yusha144.

Мод использует BepInEx, Il2CppInterop и интерфейсы Unity. Их двоичные файлы не входят в репозиторий и установочный ZIP MapHints. При отсутствии нужных файлов установщик скачивает зависимости с серверов BepInEx:

- [BepInEx 6.0.0-be.788](https://builds.bepinex.dev/projects/bepinex_be): [исходники 5b766a3](https://github.com/BepInEx/BepInEx/tree/5b766a3), [лицензия](https://github.com/BepInEx/BepInEx/blob/5b766a3/LICENSE).
- [Базовые библиотеки Unity 6000.0.66](https://unity.bepinex.dev/libraries/6000.0.66.zip).

Адреса и контрольные суммы зависимостей зафиксированы в установщике. Компоненты сохраняют условия своих правообладателей.

MapHints является неофициальным модом для Heroes of Might and Magic: Olden Era. Демонстрационный снимок содержит графику и интерфейс игры. MIT проекта не предоставляет прав на эти сторонние элементы изображения. Игровые ресурсы отдельно не распространяются.
