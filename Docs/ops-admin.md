# Установка и удаление MapHints

## 1. Что потребуется

Windows x64 и собственная игра Heroes of Might and Magic: Olden Era, Steam build 25672315. Для первой установки нужен интернет: установщик загружает BepInEx Unity.IL2CPP 6.0.0-be.788 и базовые библиотеки Unity 6000.0.66 с серверов BepInEx. Скачанные файлы проверяются по SHA-256. При обновлении с уже установленными совпадающими зависимостями повторная загрузка не нужна.

Используется именно сборка загрузчика 788 с [официальной страницы BepInEx](https://builds.bepinex.dev/projects/bepinex_be). [Общие сведения об установке BepInEx IL2CPP](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html).

Архив `OldenEra-MapHints-0.3.12.zip` содержит `Install.bat`, `Uninstall.bat`, папку `_files` с модом и установочными сценариями, документацию и сведения о сборке. Все части нужно распаковать вместе. Игровые файлы и личные настройки в архив не входят.

## 2. Установка

1. Скачайте установочный ZIP и файл `.zip.sha256` из [Releases](https://github.com/yusha144/OldenEra-MapHints/releases), когда выпуск появится. До публикации используйте предоставленный автором проверочный архив. Source code не является установочным архивом.
2. При необходимости проверьте архив в PowerShell: `Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'`. Значение должно совпасть с соседним файлом `.sha256`.
3. Распакуйте весь ZIP в отдельную папку вне каталога игры. Закройте игру.
4. Запустите `Install.bat`. Проверьте найденный путь к папке с `HeroesOldenEra.exe`. Если найдено несколько копий, выберите нужную; если игра не найдена, вставьте путь самостоятельно. Подтвердите установку.
5. Дождитесь сообщения об успешной установке. Если загрузчика ещё нет, дождитесь скачивания зависимостей. При ошибке контрольной суммы установщик остановится до изменения файлов игры.
6. Запустите игру через Steam. Первый запуск с BepInEx может занять больше времени, поскольку загрузчик создаёт библиотеки для мода.

Установщик сохраняет предыдущие файлы в `BepInEx/MapHints-backups/<дата-идентификатор>` и устанавливает DLL в `BepInEx/plugins/MapHints/OldenEra.MapHints.dll`. Старые дубликаты этой DLL в других папках plugins также сохраняются в копии и убираются. При ошибке копирования установщик пытается автоматически восстановить уже заменённые файлы и сообщает результат.

Существующие настройки сохраняются. Отличающийся загрузчик или отключённый `doorstop_config.ini` не заменяются автоматически: установщик остановится с объяснением. Нужна отдельная проверка совместимости существующей установки.

## 3. Проверка и настройки

Загрузите карту и выберите героя. У видимых объектов должны появиться отметки. Нажмите F8 несколько раз и проверьте три режима. В `BepInEx/LogOutput.log` найдите `Map Hints 0.3.12 loaded`. Сообщение `supports Steam build 25672315 only` означает, что игровые файлы не подходят.

Файл настроек создаётся при первом запуске: `BepInEx/config/local.oldenera.maphints.cfg`. Меняйте его при закрытой игре. Следующий фрагмент меняет только указанные параметры существующей секции:

```ini
[Display]
Enabled = true
Mode = All
MarkerScale = 0.84
```

Для изменения F8 откройте `BepInEx/config/OldenEra.hotkeys.cfg`. Если этого файла нет и сохранился старый `yusha144.hotkeys.cfg`, мод использует его. Если есть оба, приоритет у `OldenEra.hotkeys.cfg`. В секции `Hotkeys` измените только `MapHints`, сохранив другие записи:

```ini
[Hotkeys]
MapHints = F8 + LeftControl
```

После изменения перезапустите игру. Значение `None` отключает клавишу. [Все параметры](general.md#3-настройки).

## 4. Обновление и откат

Для обновления распакуйте новый установочный архив отдельно и выполните установку при закрытой игре. Настройки MapHints, общие клавиши и другие моды сохранятся.

Для отката найдите резервную копию, путь к которой показал установщик. Файл `backup.json` перечисляет сохранённые файлы. При закрытой игре верните прежнюю DLL в `BepInEx/plugins/MapHints`; если нужно, верните собственный файл настроек MapHints. Не возвращайте дубликаты DLL в plugins и не копируйте всю резервную папку поверх игры. Если нужно вернуть общие клавиши, сначала сравните их с текущим файлом, чтобы сохранить изменения других модов. Откат мода не возвращает старую версию самой игры.

## 5. Удаление

1. Закройте игру.
2. Запустите `Uninstall.bat` из распакованного установочного архива.
3. Проверьте путь и подтвердите удаление.

Будут удалены все копии `OldenEra.MapHints.dll` внутри `BepInEx/plugins`. Личные настройки MapHints, общие клавиши, резервные копии, BepInEx и другие моды сохранятся. Удаление работает и после обновления игры; интернет не нужен.

Для полного сброса настроек дополнительно удалите только `BepInEx/config/local.oldenera.maphints.cfg`. Общие файлы клавиш удалять не нужно. Без установочного архива можно вручную удалить DLL MapHints и её дубликаты из plugins при закрытой игре. Не удаляйте всю папку BepInEx.

## 6. Проверка без установки и типовые ошибки

Из папки распакованного архива можно проверить совместимость без скачивания и изменения игры:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_files\Install.ps1 -GamePath '<папка игры>' -VerifyOnly -NonInteractive
```

| Сообщение или симптом | Что сделать |
|---|---|
| Это исходники установщика | Скачайте установочный ZIP вместо Source code |
| Версия игры не подходит | Проверьте Steam build и дождитесь совместимой версии мода |
| Другой или изменённый загрузчик | Сообщите его версию автору |
| Загрузка не удалась | Проверьте доступ к серверам BepInEx и повторите; до завершения подготовки игра не меняется |
| Отказано в доступе | Проверьте, закрыта ли игра и есть ли право записи в выбранную папку |
| Нет отметок | Выберите героя, проверьте F8, Display.Enabled, видимость объектов и журнал |
| Нет панели навыков | Сначала познакомьтесь со зданием своим героем |
