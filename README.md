# MapHints для Olden Era

Подсказки о наградах и посещённых объектах прямо на карте Heroes of Might and Magic: Olden Era. Мод помогает выбрать маршрут для текущего героя и вспомнить, какие бонусы ещё доступны.

Подготавливается версия **0.3.12**. Публичного выпуска пока нет. Поддерживается Windows x64, Steam build **25672315**, Unity **6000.0.66**, BepInEx Unity.IL2CPP **6.0.0-be.788**. При другой версии игровых файлов мод отключает подсказки.

[Установка и удаление](Docs/ops-admin.md) · [Возможности и настройки](Docs/general.md) · [Сборка из исходников](Docs/publishing.md) · [Страница выпусков](https://github.com/yusha144/OldenEra-MapHints/releases)

## Что делает мод

- Показывает значки ресурсов, опыта, характеристик и других наград рядом с видимыми объектами.
- Учитывает выбранного героя: доступные бонусы яркие, использованные приглушены, невыполненные условия отмечены оранжевым.
- Помечает обновляемые награды: 7 означает неделю, 1 означает день. Разделитель / показывает выбор одной награды.
- У мельницы и волшебного сада показывает кубик случайной награды, не раскрывая её заранее.
- После знакомства со зданием показывает известные навыки университета, Мудрого сыча и Зловещего театра. До знакомства дополнительной панели нет.
- Клавиша F8 переключает все отметки, только доступные награды и скрытие. Клавишу и размер отметок можно изменить.

Мод не меняет баланс и сохранения. Подсказка о навыке описывает известное предложение здания; она не гарантирует итоговый уровень навыка или возможность обучения конкретного героя. [Ограничения](Docs/general.md#4-ограничения-и-ошибки).

## Установка

Готовый установочный архив будет размещён в [Releases](https://github.com/yusha144/OldenEra-MapHints/releases) после проверки в игре. Архивы Source code предназначены для разработки.

Распакуйте установочный архив, закройте игру и запустите `Install.bat`. Установщик найдёт игру, проверит её версию и при необходимости скачает зависимости с серверов BepInEx. Для удаления предусмотрен `Uninstall.bat`. [Подробная инструкция](Docs/ops-admin.md).

## Для разработки

`source/` содержит код мода, `tests/` проверки правил и установщика, `installer/` исходники установщика, `Docs/` документацию. `Build-Release.ps1` собирает готовый архив из выбранного коммита и записывает контрольную сумму. Сборка и проверки выполняются локально.

Игровые библиотеки берутся из собственной установленной копии игры через `GameRoot`. В Git нет DLL игры, сохранений, личных настроек и готовых сборок. [Команды сборки и порядок выпуска](Docs/publishing.md).
