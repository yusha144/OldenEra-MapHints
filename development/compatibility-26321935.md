# Совместимость со сборкой 26321935

Проверено 2 ноября 2026 года на установленной копии Steam, Unity 6000.0.66f1, BepInEx 6.0.0-be.788. Проверка SHA-256 сохранена для новой GameAssembly.dll и global-metadata.dat.

Сборка выполнена с заново созданными библиотеками BepInEx/interop. Игру в ходе обновления не запускали. Внешний вид и работа в настоящей игровой сессии требуют проверки игроком.

Обновлены обращения к карте, выбранному герою, объектам, наградам, значкам, окнам и локализации. Автономные проверки: 145 утверждений на актуальном Core.zip.

В новом двоичном коде fpj.bnov читает список посещений и тип посещения, fpj.bnmj сначала вызывает эту проверку, затем проверку готовых наград flc.bmpr. Методы не исполняют взаимодействие с объектом.

## Исправление чтения состояния окон

После игровой проверки обнаружено неверное сопоставление свойства BhScreen.cvrc: его getter udd возвращает постоянное true. Открытое состояние читает BhScreen.cvrd через udg, поле cekd по смещению 0x82. Метод udk выставляет его при открытии, udl сбрасывает при закрытии. Новая DLL читает cvrd. Проверка ScreenStateChecks читает метаданные собранной DLL и запрещает ссылку на ошибочный getter.

Дополнительно исправлена ссылка выбранного героя fqt.crlp с getter bnwc. Предыдущий вариант читал fqt.crlo и мог отвергать героя из-за несовпадения указателей. Проверка SelectedHeroChecks воспроизвела ошибку на прежней DLL и прошла после исправления. Вспомогательные методы HintOverlay скрыты через HideFromIl2Cpp; проверка метаданных оставляет открытыми только Awake, Update, OnGUI и OnDestroy.
