# Разработка MapHints

## 1. Структура

| Папка | Содержимое |
|---|---|
| source | Код мода и каталог объектов |
| installer | Установщик и удаление |
| docs | Инструкции для игрока и демонстрационный снимок |
| development/tests | Проверки правил мода и установщика |
| development/artifacts | Локальные результаты сборки и временные файлы, исключённые из Git |

`development/Build-Release.ps1` собирает установочный архив. `development/release-settings.json` содержит пути проектов, версию загрузчика и контрольные суммы зависимостей и игровых файлов.

## 2. Сборка и проверки

Нужны Windows, Git, Windows PowerShell 5.1, .NET SDK 8 или новее и совместимая копия игры. Установленный BepInEx 6.0.0-be.788 создаёт `BepInEx/interop` при первом запуске игры. Эти библиотеки используются для сборки мода и не хранятся в Git.

Команды выполняются из корня репозитория:

```powershell
dotnet run --project .\development\tests\Tests.csproj -c Release -- '<папка игры>\HeroesOldenEra_Data\StreamingAssets\Core.zip'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\development\tests\Installer.Tests.ps1
dotnet build .\source\MapHints.csproj -c Release '-p:GameRoot=<папка игры>'
```

Мод рассчитан на net6.0, проверки правил на net8.0. Проверки установщика работают с искусственными папками в `development/artifacts/installer-tests`. Они проверяют установку, обновление, сохранение соседних модов и настроек, обработку ошибок и удаление.

## 3. Установочный архив

Сначала зафиксируйте изменения в Git. Сборщик использует выбранный коммит, включая его версии документации и установщика:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\development\Build-Release.ps1 -GameRoot '<папка игры>' -Revision HEAD
```

Скрипт должен совпадать с версией из выбранного коммита. Сборщик проверяет игровые файлы, запускает проверки, собирает DLL и сверяет её версию. Для расчёта состава зависимостей он загружает закреплённые архивы BepInEx и Unity. Параметры `-LoaderArchive` и `-UnityLibrariesArchive` позволяют использовать локальные копии с теми же SHA-256.

Результат находится в `development/artifacts/releases`. Параметр `-OutputDirectory` задаёт другую папку. Существующие файлы не перезаписываются.

| Файл | Содержимое |
|---|---|
| `OldenEra-MapHints-<версия>.zip` | Install.bat, Uninstall.bat, папка _files, README, MIT и инструкции из docs |
| `.zip.sha256` | SHA-256 архива |
| `.release.json` | Версия, коммит, имя тега по версии и SHA-256 |

Внутри архива `release-manifest.json` содержит контрольные суммы поставляемых файлов. `_files/manifest.json` содержит устанавливаемые файлы и зависимости. Проверки, инструменты разработки, игровые DLL и личные настройки в установочный ZIP не входят.

Сборщик не запускает игру и не устанавливает мод. Он не создаёт теги и Releases и не отправляет файлы на GitHub. Поле `gameplayVerified = false` означает, что сборщик не выполняет игровую проверку. Автоматические проверки не оценивают внешний вид подсказок и сетевую совместимость.

## 4. Работа мода

`Plugin` сверяет SHA-256 игровых файлов и создаёт `HintOverlay`. Отметки строятся по видимым объектам, выбранному герою, посещениям и действующим бонусам. Каталог находится в `source/object-catalog.json`, правила доступности в `VisitRules` и `BuffHintRules`.

Список известных навыков читается из состояния игры после знакомства со зданием. Мод не генерирует награды и не ведёт отдельную историю посещений. Сохранения игры остаются источником этих сведений.
