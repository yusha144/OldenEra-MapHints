- global-metadata.dat SHA-256 `C40298DE4A952A0CE5158BF07C392335EEA1F6B39B544101FF04B974794D1105`.

Сборка использует заново созданные библиотеки BepInEx/interop. Обращения сопоставлены по типам, сигнатурам, свойствам и связям вызовов установленной игры.

| Метод | RVA | Назначение |
|---|---|---|
| `BhScreen.udl` | `0x2EADE30` | Флаг открытого окна, поле 0x82 |
| `fqt.bnwu` | `0x5F3BD0` | Выбранный герой, поле 0x30 |
| `fpj.bnpn` | `0x24C0670` | Проверка посещений и типа посещения |
| `fpj.bnnb` | `0x24BFE10` | Проверка посещения, затем готовности награды |

BhScreen.cvsd читает флаг открытия через udl по смещению 0x82. Свойство cvsc с getter udi возвращает постоянное true и в проверке видимости не используется.

Выбранный герой читается через fqt.crmp и bnwu, поле 0x30. Проверки метаданных собранной DLL сверяют оба обращения. Автономные проверки правил используют актуальный Core.zip.

Игра в ходе работы не запускалась. Работа в настоящей сессии и внешний вид требуют проверки пользователя.
